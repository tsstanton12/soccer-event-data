# SoccerTrack v2 Local Data

Place downloaded SoccerTrack v2 files here. Match data is intentionally
excluded from Git.

Start with one match:

```text
data/soccertrack/<match_id>/bas/<match_id>_12_class_events.json
data/soccertrack/<match_id>/videos/<match_id>_panorama_1st_half.mp4
data/soccertrack/<match_id>/videos/<match_id>_panorama_2nd_half.mp4
```

Later, add the matching GSR files:

```text
data/soccertrack/<match_id>/gsr/<match_id>_1st.json
data/soccertrack/<match_id>/gsr/<match_id>_2nd.json
```

SoccerTrack v2 is CC BY 4.0. Preserve attribution in derived data.
